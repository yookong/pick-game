# 작은 방의 보물들

왼쪽 배출구에 인형을 떨어뜨려 도감을 채우는 세로형 모바일 PWA입니다. 첫 시리즈 **인형 친구들**은 오리지널 인형 12종으로 구성됩니다.

## Windows에서 실행

Node.js 24와 pnpm 11.25.0을 사용합니다.

```powershell
pnpm install --frozen-lockfile
pnpm dev
```

터미널에 표시되는 주소를 엽니다. 휴대폰으로 개발 서버에 접속할 때는 같은 네트워크에서 `pnpm dev --host 0.0.0.0`을 실행하고 PC의 LAN 주소를 사용하세요. 오프라인과 설치를 검증할 때는 HTTPS 또는 브라우저가 신뢰하는 localhost에서 프로덕션 빌드를 열어야 합니다.

```powershell
pnpm build
pnpm preview
```

배포할 때는 `dist/`를 정적 호스팅에 올립니다. 최초 온라인 방문에서 서비스 워커 설치가 완료되면 오프라인으로 실행됩니다. iOS에서는 Safari의 공유 메뉴에서 ‘홈 화면에 추가’를 사용할 수 있습니다. 새 서비스 워커는 기존 페이지가 닫힐 때까지 대기합니다.

## GitHub Pages 공개 테스트

저장소의 **Settings → Pages → Build and deployment → Source**에서 **GitHub Actions**를 선택합니다. **Actions → Deploy game to GitHub Pages → Run workflow**에서 `main`을 실행하면 프로덕션 빌드가 배포됩니다. 이후에는 `main`에 푸시할 때마다 자동으로 다시 배포합니다. 배포가 끝나면 [게임 열기](https://yookong.github.io/pick-game/)로 접속합니다.


## 조작과 경제

- 첫 시작에 코인 120개를 받습니다. 뽑기를 시작하면 10개를 사용합니다. 조이스틱을 왼쪽이나 오른쪽으로 누르거나 드래그해 집게를 움직입니다. 키보드는 ←/→ 또는 A/D, 하강은 Space입니다. 12초가 지나면 자동으로 내려갑니다.
- Matter.js가 인형끼리의 충돌, 집게의 밀기, 떨어지는 동작을 처리합니다. 양쪽 집게에 실제로 닿은 인형은 질량과 중심 오차에 따라 일시적으로 잡힐 수 있습니다. 인형 중심이 왼쪽 배출구의 획득 영역에 들어가면 각각 한 번씩 얻습니다.
- 일반 집게의 기본 유지 시간은 0.2초입니다. 강한 집게가 나온 뒤 다음 간격을 1~15회에서 균등하게 정하고, N번째 시도에 강한 집게를 적용합니다. 첫 간격도 같은 방식으로 정합니다. 위치, 접촉, 무게가 물리 결과를 결정합니다. 도감 희귀도는 수집용 표기입니다.
- 출석과 미니게임은 기기의 현지 날짜 기준으로 초기화됩니다. 7일 출석표는 출석한 날에만 한 칸씩 진행하며 7번째 이후 순환합니다. 미니게임은 시작할 때 하루 세 번의 기회 중 하나를 사용하며, 목표 구간과의 거리에 따라 코인 2·6·12개를 받습니다.
- 교환소에서 선택한 중복 인형을 조각으로 교환합니다. 인형마다 한 개를 보존합니다. 조각 8개로 코인 10개를 교환할 수 있습니다.

## 저장과 복구

- IndexedDB에 스키마 버전 1로 저장합니다. 코인 차감과 예약 간격 기록은 한 트랜잭션에서 처리합니다. 뽑기가 끝나면 실제 배출 결과, 보유 수량, 남은 배치를 함께 저장합니다.
- 시도 중 새로고침하거나 종료하면 다음 실행에서 1회 비용을 한 번 환불합니다. 시도 횟수와 강한 집게 예약 간격은 차감 시점의 값을 유지합니다. 마지막으로 완료된 기계 배치로 돌아갑니다. 중단된 미니게임의 기회는 사용 처리합니다.
- 완료된 시도 사이에 남은 인형의 위치와 각도를 유지합니다. 남은 인형이 3개 미만이면 다음 시도를 위해 15개로 새로 배치합니다. 속도는 시도 시작 시 0에서 출발합니다.
- 앱이 숨겨지면 시뮬레이션과 타이머가 멈춥니다. 다시 보일 때 이어서 진행하고 눌려 있던 이동 입력은 초기화합니다.
- 설정에서 JSON 백업을 내보내거나 불러올 수 있습니다. 저장이 손상되면 복구 화면에서 원본을 보존한 뒤 백업 가져오기 또는 새 저장 만들기를 선택할 수 있습니다. 지원하지 않는 저장 버전은 가져오기 단계에서 거절됩니다.
- Web Locks를 지원하는 브라우저에서는 동일 출처의 게임 탭을 하나로 제한합니다. 다른 브라우저에서는 저장 트랜잭션은 직렬화되지만, 동시 플레이 시 다른 탭이 진행 중인 시도를 중단된 시도로 회수할 수 있으므로 탭 하나로 플레이하세요. 서버가 없어 기기 날짜 변경과 로컬 저장 조작을 완벽히 방어할 수 없습니다.

## 테스트 모드

`pnpm dev` 또는 다음 명령으로 실행하고 **설정 → 물리 테스트 도구**를 엽니다.

```powershell
pnpm lab
pnpm preview --outDir dist-lab --port 4175
```

코인·조각 증감, 출석·미니게임 초기화, 아이템 지급, 도감 해금, 강한 집게 예약과 모드 고정, 예약 간격 확인, 힘·유지 시간·질량·마찰·미니게임 한도 조절, 배치 초기화, 충돌·배출 영역 표시, 시드 설정, 백업 및 확인 후 전체 초기화를 지원합니다. 수치 입력값은 입력란을 벗어날 때 적용됩니다. 이 도구의 변경은 해당 브라우저에만 적용됩니다. 서버 권한을 부여하는 관리자 시스템과는 별개입니다. 일반 빌드의 번들에는 테스트 화면과 진입 경로가 포함되지 않습니다.

## 검증

```powershell
pnpm typecheck
pnpm test
pnpm build
pnpm exec playwright install chromium
pnpm test:browser
```

이미 설치한 Chrome을 쓰려면 `PICK_CHROME` 환경 변수에 실행 파일 경로를 지정합니다. Playwright는 4173과 4174 포트를 사용합니다. 핵심 테스트에는 약한 집게로 배출구 쪽 인형 움직이기, 강한 집게로 들어 올리기와 빗나가기, 실물 획득 판정, 정산 중복 방지, 저장 복구 및 교환이 포함됩니다. 브라우저 테스트는 iPhone 13 mini 크기의 Chromium 터치 에뮬레이션에서 오프라인 획득 및 도감 저장, 새로고침 환불, 출석·미니게임 한도와 개발 빌드 교환을 확인합니다.

실기기 확인 목록

- iPhone 13 mini Safari의 주소창 확장·축소, 홈 화면 설치, safe-area 및 오프라인 재실행
- 터치 드래그, 멀티터치 취소, 화면 잠금·복귀, 소리 및 배터리 사용량
- 실제 기기의 장시간 플레이에서 인형 배치별 난이도와 일반·강한 집게 힘 비교

## 코드 구조

- `src/claw.ts`는 브라우저와 독립적인 Matter.js 시뮬레이션입니다. 물리 화면은 React/SVG로 렌더링하여 별도의 Phaser 씬과 렌더러 의존성을 줄였습니다.
- `src/catalog.ts`의 아이템 정의와 `src/art.tsx`의 자체 벡터 아트를 별도로 관리합니다. `src/state.ts`는 경제·보상·저장 모델을, `src/storage.ts`는 IndexedDB 어댑터를 담당합니다.
- Vite가 정적 웹 셸을 빌드합니다. 앱 패키징 시 웹 셸을 Capacitor 등에 넣고 필요에 따라 저장·소리·진동 어댑터를 교체할 수 있습니다.
